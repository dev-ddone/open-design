# 2.5.0-alpha.1 — Smart editor

## Added

- Editable tables, grids and frames.
- SVG palette replacement.
- Layers panel, grouping, context menu and precision controls.
- Keyboard shortcuts and improved Wikimedia reliability.
- Server foundation for favorites, recents and named collections.

## Known limitations

Favorites and recents were still primarily browser-local in this release. Image blend and dissolve results remained rasterized outputs.
