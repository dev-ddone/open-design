# 2.8.0-alpha.1 — Semantic templates and static production

## Added

- Semantic object fields for text, price, CTA, image and logo.
- Required fields, readable labels, defaults and serialized field metadata.
- Template validation for missing values, duplicate keys and incompatible object types.
- CSV parsing with quoted fields and comma/semicolon detection.
- Apply one data record to the open page.
- Generate up to 100 static pages from CSV with a safety version before mutation.
- Static campaign variants created as separate designs with their own dimensions.
- CSV and Markdown attribution reports.
- Unit coverage for field normalization, CSV parsing and serialized data merge.

## Changed

- Design Audit now validates semantic template fields.
- Smart Resize can preserve the source project by creating a separate resized design.

## Known limitations

- CSV is implemented directly; native XLSX parsing remains planned.
- Generated pages are independent after creation and are not live-linked to the source template.
- Semantic image fields accept a resolvable image URL; an integrated asset-picker replacement flow remains future work.
- Smart Resize uses geometric scaling and relative placement, not AI-driven semantic reflow.
