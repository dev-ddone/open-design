# 2.10.0-alpha.1 — Governed export and page overview

## Research basis

This release applies static-editor patterns observed in Canva's page grid and approval workflows, Adobe Express review controls, and Figma document navigation: large-page overview, non-destructive navigation, visible quality gates and explicit permission-aware overrides.

## Added

### Export governance

- Preflight before PNG, JPG, SVG and PDF export.
- Design Audit execution over the page or complete document being exported.
- Review-status and unresolved-comment checks.
- Blocking conditions for audit errors and `CHANGES_REQUESTED` review state.
- Warning conditions for draft/in-review status, audit warnings and open comments.
- Direct actions to open Design Audit or Review from the preflight dialog.
- Explicit Editor override rather than silent export.
- Non-bypassable blockers for Viewer/read-only sessions.
- Immediate export for approved, clean documents.

### Page overview

- Full-screen searchable page grid.
- Reusable high-resolution page thumbnail renderer.
- Open, rename, duplicate, delete and add actions from the overview.
- Drag-and-drop page ordering when the full page set is visible.
- Atomic page-order API with complete-list validation.
- Conflict response when the document changed before ordering was saved.
- Compact page bar entry point for the grid overview.

## Validation

- TypeScript typecheck.
- Export-governance unit tests for Viewer blocks, Editor overrides and clean approval paths.
- Frontend production build.
- Runtime page creation, persisted reverse order and incomplete-list rejection.
- Existing migrations, account, ACL, review, Elements, preference, realtime and provider workflows.
- Production Docker image build.

## Known limitations

- Export preflight evaluates currently loaded canvas pages; export golden-file and browser visual regression coverage remain pending.
- Editors can intentionally override blockers, but override events are not yet written to an audit log.
- The page grid uses desktop drag-and-drop; keyboard and touch reordering require dedicated controls.
- Page thumbnails are generated client-side and are not yet cached as persistent preview assets.
