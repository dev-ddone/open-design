# 2.9.0-alpha.1 — Contextual review and multi-format campaigns

## Research basis

This release applies recurring static-editor patterns observed in Canva, Adobe Express, Figma and VistaCreate: contextual comments over the design, comment filtering, comment-only access, explicit copy-and-resize behavior and multi-format campaign creation.

## Added

- Numbered comment pins rendered over the corresponding canvas page.
- Object-linked pins follow the Fabric object when it moves.
- Page-level pin coordinates stored as normalized values.
- Comment filters for open/resolved/all, current page and selected object.
- Comment search by author, body and mention.
- Thread replies using the existing parent-comment relationship.
- `@mention` metadata extraction and persistence.
- Review panel access for Viewer/read-only sessions.
- Multi-select Smart Resize presets.
- Group selection and recently used resize formats.
- Batch creation of multiple independent campaign projects from one source.
- Direct links to every generated campaign variant.
- Migration `006_design_comment_anchors.sql`.

## Changed

- Smart Resize no longer requires one format per operation.
- Review comments use explicit resolution state instead of implicit toggle-only behavior.
- The right panel keeps editing tools hidden for Viewer sessions while retaining the review workflow.

## Validation

- TypeScript typecheck.
- Unit and regression tests for resize planning, mentions and pin coordinates.
- Frontend production build.
- Migrations 001–006 and runtime bootstrap.
- Anchored comment, mention, movement, resolution and approval smoke test.
- Existing account, ACL, template, Elements, preference and realtime workflows.
- Production Docker image build.

## Known limitations

- Mention metadata is stored and displayed, but email/in-app mention delivery is not implemented yet.
- Pins are positioned from the page/object state; freehand pin dragging is not exposed yet.
- Batch resize produces independent projects rather than live-linked variants.
- Resize remains geometric and does not perform semantic text reflow.
