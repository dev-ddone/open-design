# 2.6.0-alpha.1 — Static quality suite

## Added

- Authenticated synchronization bridge for favorite element IDs, complete favorite cards, recent elements and collections.
- Migration `004_element_preference_items.sql`.
- Static Smart Resize with social, print and presentation presets.
- Design audit for off-canvas objects, small text, brand fonts and colors, layer naming and required attribution.
- Product scope, static roadmap, versioned changelog and root handoff documentation.

## Changed

- Local storage is retained as an offline cache instead of being the only preference source.
- The right editor panel now exposes Smart Resize and Controllo design.
- Product scope explicitly excludes video editing, audio, animated timelines, GIF animation tooling and 3D.

## Known limitations

- Remote preference changes become visible after reopening the Elements panel or reloading the editor.
- Smart Resize modifies the current page; linked campaign variants are not yet implemented.
- Design Audit reports issues but does not yet block export or repair them automatically.
