# 2.4.0-alpha.1 — Static Elements universe

## Added

- Federated SVG and image search with source and license metadata.
- Bundled DDone Structures, Tabler Icons and Twemoji.
- Openverse, Wikimedia and optional stock-provider integrations.
- Creative image/vector tools and persistent imported assets.

## Changed

- The catalog was restricted to static formats the Fabric editor can actually edit or place reliably.
- Unsupported video, audio, animation and 3D promises were removed from the active product surface.
