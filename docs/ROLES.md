# Roles

## OWNER

- full workspace access;
- member and role management;
- client, design, template, brand kit and asset management;
- realtime editing and export.

## ADMIN

- member and role management except ownership transfer;
- client, design, template, brand kit and asset management;
- realtime editing and export.

## EDITOR

- create and update clients;
- create, edit and delete designs and pages;
- upload assets and use the elements library;
- realtime editing and export.

## VIEWER

- list and open permitted workspace designs;
- receive realtime changes;
- navigate pages, zoom and export PNG;
- cannot create, modify, upload or delete.

## Enforcement

The web interface adapts to the role, but all important restrictions are also enforced by API middleware and tenant-aware SQL queries.
