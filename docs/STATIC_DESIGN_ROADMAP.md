# Static design roadmap

## Implemented foundation

- multi-page Fabric editor;
- compact page strip and searchable page-grid overview;
- atomic page ordering with stale-list protection;
- precise positioning, grouping, layers and keyboard controls;
- editable tables, grids and frames;
- local and federated static asset search;
- organization/client permissions and private storage;
- realtime object synchronization and versions;
- brand kits and controlled template policies;
- synchronized favorites, recent elements and collection storage;
- static Smart Resize with multi-format campaign copies;
- design audit for brand, layout, accessibility, templates and licenses;
- semantic placeholders for text, image, logo, price and CTA;
- required semantic fields and validation;
- CSV row-to-page generation;
- comments anchored to pages and objects;
- canvas comment pins, replies, filters and mention metadata;
- review states and Viewer-safe commenting;
- approval/audit/comment export preflight;
- attribution reports.

## Next release gates

### Template and brand intelligence

- integrated asset-picker replacement for semantic image/logo fields;
- image replacement without losing crop;
- one-click document-wide brand and logo migration;
- template variant families and inherited updates.

### Agency governance

- persistent log for export overrides and approval decisions;
- drag-to-position comment pins and rectangular regions;
- mention, assignment and approval notifications;
- unread comment state and reviewer inbox;
- stronger review history reporting.

### Data-driven production

- native XLSX import;
- record preview and column mapping;
- editable data-bound tables and charts;
- QR/barcode values bound to records;
- batch ZIP export for generated pages and campaign variants;
- optional live-linked records and campaign families.

### Multipage navigation

- keyboard page ordering controls;
- touch-friendly page reordering;
- persistent thumbnail caching;
- section/group labels for very large documents.

### Reliability

- Playwright editor journeys;
- screenshot visual regression;
- export golden-file comparisons;
- reconnect/offline collaboration tests;
- keyboard-only and WCAG acceptance tests;
- tablet layout acceptance tests.

### Platform extension

- command palette and searchable shortcut reference;
- plugin/extension SDK;
- documented public integration contracts.

Video, audio, animated timelines and 3D are intentionally excluded.
